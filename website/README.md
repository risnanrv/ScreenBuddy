# ScreenBuddy Static Website

This directory contains the official minimal static landing page for ScreenBuddy.

## Deployment Options

### Option 1: GitHub Pages (Recommended)
1. In your GitHub repository (`risnanrv/ScreenBuddy`), go to **Settings** > **Pages**.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select branch `main` and folder `/website`.
4. Click **Save**. The website will be deployed automatically at `https://risnanrv.github.io/ScreenBuddy/`.

### Option 2: Vercel
1. Import `risnanrv/ScreenBuddy` in Vercel.
2. Set **Root Directory** to `website`.
3. Framework Preset: **Other / Static**.
4. Click **Deploy**.
